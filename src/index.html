Kubarr brings application lifecycle and cluster visibility into a single interface while your workloads stay on your own infrastructure.

01 / DEPLOY

Curated app catalog

Install supported apps such as Sonarr, Radarr, qBittorrent, Plex and Jellyfin through the dashboard, backed by Helm charts.

02 / OBSERVE

See what is happening

Check application status, resource metrics and logs from one place when something needs attention.

03 / ORGANIZE

Built on Kubernetes

Apps run in separate namespaces; the gateway, API and worker coordinate access and lifecycle operations.
