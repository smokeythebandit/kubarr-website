Documentation

Kubarr is a dashboard and installer for managing self-hosted applications on Kubernetes. Start with the installer, then explore how the platform fits together.

01 / Getting started →Prerequisites, CLI build, bootstrap and access.02 / How it works →Gateway, API, worker and the app catalog.

Source of truth

The application repository contains the CLI and application code. The charts repository contains platform components and supported app charts. These introductory pages reflect the current CLI bootstrap flow; for deeper configuration and chart-specific storage or networking notes, consult those repositories.

Important: Some older Kubarr guides mention a single kubarr umbrella Helm chart. The current charts repository does not have one; use the CLI bootstrap described here.
